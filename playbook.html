📋 The Playbook — from DealMachine to Instantly

The whole outreach pipeline, step by step. Open this page whenever you forget where you are. Every step is done in the normal DealMachine website + this tool — no API, no code.
🏠 Open the List Expander tool →
DealMachine list (free) → Export CSV → ① Expander → ② MillionVerifier → ③ Stage B → ④ Instantly

1Build lists in DealMachine — FREE

Find Properties → enter the 5 zips → add filters → Build List. Building lists costs nothing; credits are only charged at export.

  • Base zips: 95608 95610 95621 95628 95662
  • Roseville expansion (added 2026-08-07): 95661 95678 95747 — 52,582 SFRs. ⚠️ Placer's data feed is WEAK on Tax Delinquent / Vacant / Probate (1–15 records — don't bother) and its Building Condition field is garbage (95% marked Poor/Fair — never use condition there). What works in Roseville: Likely to Move (1,097) · Utility liens (672) · Corner+Tenure+Absentee (324) · Expired (270) · Private-Lender (245) · Mechanics (146) — sized live 2026-08-07
  • Property Type = Single Family (Multi Family only for the tired-landlord list)
  • ONE motivation signal per list — never mix signals, or you can't tell later which one produced the replies. (Several lists can feed ONE combined pull later — DealMachine dedupes repeat access within the billing cycle, so separate signal lists cost the same as one big OR list and keep attribution.)

🚫 NEVER add a lot-size filter in DealMachine — the UI's included. The lot filter is silently broken in DealMachine's search engine (the UI and API share it). Proof from this account (2026-08-07): 95608 corner lots = 2,887; adding "lot ≥ 0.25 acres" = 2,764 — it removed only 4%, when real data shows only ~37% of local lots are that big. The saved search "95608 Active Corner Lots - Min 0.25 Acres" showing 2.8K is this bug in action — the true corner + active + ≥0.25 count is 23. You'd think you filtered; you didn't. Lot screening happens reliably in your downloaded CSV instead (the lot column exports correctly — only the filter is broken).
⚠️ Quick Filters combine with OR by default (property matches ANY selected filter). The "Match All" toggle switches to AND. For these lists you only ever add one signal, so it rarely matters.

2Export the list from DealMachine — THIS is where credits are spent

  1. Open the list → Select all (⇧S)
  2. Click Export → Format: Property List
  3. Contact Audience: Property Owners — this attaches owner names, up to 3 phones + 3 emails per contact (people credits, ~1 per contact). ⚠️ There is NO cheaper option: exports force-attach up to 5 skip-traced contacts per property and bill their people credits regardless of settings (the documented 2,756-credit surprise) — budget ~2.7 credits per property all-in.
  4. Fields to tick: Owner Mailing Address · Lot Size Acres · Year Built · Last Sale Date · Estimated Value · Estimated Equity % · Market Status · Zoning · Sewer · Garage Type · Parcel ID · Is Corner Lot · Building Condition · Foreclosure/Preforeclosure Status · Tax Delinquent Year
  5. Download the CSV from the Inbox (bell icon) when it finishes

3Expand the CSV — the List Expander tool, Stage A

  1. Choose the exported CSV → check the BEFORE table (full list, numbered rows)
  2. Click Expand

What it does automatically — no settings, nothing to remember:

  • Splits every property into one row per owner & email, each with its own contact's name (a couple = two people, each greeted correctly)
  • Removes exact duplicate emails (DealMachine often lists the same person twice) — count shown
  • Flags pre-foreclosure owner-occupied records (do_not_email_1695) — kept visible, excluded later at Stage B for legal safety
  • Keeps EVERYTHING else — no filters, no property ever disappears
  1. Download _toverify.csv
⚠️ Eyeball the AFTER table for rows whose market status turned Active/Pending/Sold since the pull — actively-listed owners belong to their agent, and Sold means they may not own it anymore. Delete those rows from the final file before Instantly.

4Verify emails — MillionVerifier

  1. Go to millionverifier.com → upload _toverify.csv
  2. Wait for verification to finish (minutes for small lists)
  3. Download the FULL results file — the one that includes a result column per email (values: ok / catch_all / unknown / invalid — only "ok" survives stage B). Not the "good only" file!
✅ Why verify: sending to dead addresses = bounces = burned sending domains. Never upload an unverified list to Instantly. Verification costs pennies per email.

5Final list — the List Expander tool, Stage B

  1. Choose the same _toverify.csv + the MillionVerifier results file → Run Stage B
  2. Download _instantly.csv

What it does: keeps only emails MillionVerifier said are good · one row per PERSON with that person's best working email (a property with 2 reachable owners = 2 rows) · drops the §1695-flagged rows.

6Upload to Instantly — one campaign per COPY TYPE (4 campaigns)

  1. 4 campaigns, one per COPY TYPE: Big Lot (takes utility liens, mechanics liens, tax liens & judgments, expired — lot ≥ 8,000 sq ft only) · Tax Delinquent (also takes small-lot rejects) · Vacant · Pre-Probate. Upload as many small CSVs into a campaign as you like — leads just accumulate. Per-list results still tracked: every lead carries its lanes tag, and Claude computes per-list reply stats monthly.
  2. Upload _instantly.csv → map custom variables: greeting_name · street_name · lot_sf · property_address → enable the duplicate-skip option (don't import leads already in the workspace) so nobody can ever be emailed twice
  3. Campaign settings every time: open tracking OFF · click tracking OFF · ESP matching ON · daily volume per the warmup ramp
  4. Sequences: the v6 library is already deployed in the 4 campaigns (per copy type: big-lot / tax-delinquent / vacant / long-tenure) — first-name greeting, address-first subjects, sentence-level spins, 2-line "— Vlad" signature, reply-to-opt-out line in every touch
🚫 Launch gates — ALL must be true before the first real send: warmup ≥ 3 full weeks (first send 2026-08-18 or later) · placement test ≥ 90% inbox · list verified through steps 4–5 · anyone who ever opted out stays suppressed forever.

♻️ THE MONTHLY CYCLE — only NEW properties, every month

Nobody ever gets emailed twice. Each month's outreach targets only properties never contacted before. Two safety layers make that true:

  • DealMachine layer: monthly pulls use "exclude previously exported" — only never-before-exported properties come out (and only they cost credits). Verified working on this account.
  • Instantly layer (safety net): at upload, enable the option to skip leads that already exist in the workspace/other campaigns — even if a duplicate slips through, Instantly won't email it. Opt-outs go to the blocklist forever.

Rules of thumb

  • Judge no list before ~100 sends.
  • Data goes stale in ~45 days — export → verify → send within the same month, never hoard.
  • Inbox capacity is the real constraint, not credits. Scale mailboxes before scaling lists.
  • Questions / anything weird → ask Claude (the deal-hunter skill has the full spec behind this page).
