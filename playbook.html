📋 The Playbook — from DealMachine to Instantly

The whole outreach pipeline, step by step. Open this page whenever you forget where you are. Every step is done in the normal DealMachine website + this tool — no API, no code.
🏠 Open the List Expander tool →
DealMachine list (free) → Export CSV → ① Expander → ② MillionVerifier → ③ Stage B → ④ Instantly

1Build lists in DealMachine — FREE

Find Properties → enter the 5 zips → add filters → Build List. Building lists costs nothing; credits are only charged at export.

  • Zips (always the same): 95608 95610 95621 95628 95662
  • Property Type = Single Family (Multi Family only for the tired-landlord list)
  • ONE motivation signal per list — never mix signals, or you can't tell later which one produced the replies

🚫 NEVER add a lot-size filter in DealMachine — the UI's included. The lot filter is silently broken in DealMachine's search engine (the UI and API share it). Proof from this account (2026-08-07): 95608 corner lots = 2,887; adding "lot ≥ 0.25 acres" = 2,764 — it removed only 4%, when real data shows only ~33% of local lots are that big. The saved search "95608 Active Corner Lots - Min 0.25 Acres" showing 2.8K is this bug in action — the true corner + active + ≥0.25 count is 23. You'd think you filtered; you didn't. Lot screening happens reliably in your downloaded CSV instead (the lot column exports correctly — only the filter is broken).
⚠️ Quick Filters combine with OR by default (property matches ANY selected filter). The "Match All" toggle switches to AND. For these lists you only ever add one signal, so it rarely matters.

2Export the list from DealMachine — THIS is where credits are spent

  1. Open the list → Select all (⇧S)
  2. Click Export → Format: Property List
  3. Contact Audience: Property Owners — this attaches owner names, up to 3 phones + 3 emails per contact (people credits, ~1 per contact). Leave it EMPTY only if you want a property-only export with no contact info.
  4. Fields to tick: Owner Mailing Address · Lot Size Acres · Year Built · Last Sale Date · Estimated Value · Estimated Equity % · Market Status · Zoning · Sewer · Garage Type · Parcel ID · Is Corner Lot · Building Condition · Foreclosure/Preforeclosure Status · Tax Delinquent Year
  5. Download the CSV from the Inbox (bell icon) when it finishes
Credit ruleWhat it means

🚫 Budget rule: know the cost BEFORE clicking Export. The dialog shows "Billable this export" — read it. A 1,000-property list with owners ≈ 2,700 credits.

3Expand the CSV — the List Expander tool, Stage A

  1. Choose the exported CSV → check the BEFORE table (full list, numbered rows)
  2. Click Expand

What it does automatically — no settings, nothing to remember:

  • Splits every property into one row per owner & email, each with its own contact's name (a couple = two people, each greeted correctly)
  • Removes exact duplicate emails (DealMachine often lists the same person twice) — count shown
  • Flags pre-foreclosure owner-occupied records (do_not_email_1695) — kept visible, excluded later at Stage B for legal safety
  • Keeps EVERYTHING else — no filters, no property ever disappears
  1. Download _toverify.csv
⚠️ Eyeball the AFTER table for rows whose market status turned Active/Pending/Sold since the pull — actively-listed owners belong to their agent, and Sold means they may not own it anymore. Delete those rows from the final file before Instantly.

4Verify emails — MillionVerifier

  1. Go to millionverifier.com → upload _toverify.csv
  2. Wait for verification to finish (minutes for small lists)
  3. Download the FULL results file — the one that includes a result column with good/invalid/risky per email. Not the "good only" file!
✅ Why verify: sending to dead addresses = bounces = burned sending domains. Never upload an unverified list to Instantly. Verification costs pennies per email.

5Final list — the List Expander tool, Stage B

  1. Choose the same _toverify.csv + the MillionVerifier results file → Run Stage B
  2. Download _instantly.csv

What it does: keeps only emails MillionVerifier said are good · one row per PERSON with that person's best working email (a property with 2 reachable owners = 2 rows) · drops the §1695-flagged rows.

6Upload to Instantly — one campaign per LIST

  1. One campaign per lane (Tax Delinquent, Utility Liens, Expired…) — never mix lists, or you can't tell which signal works. The lanes column says where each row belongs.
  2. Upload _instantly.csv → map custom variables: greeting_name · street_name · lot_sf · property_address
  3. Campaign settings every time: open tracking OFF · click tracking OFF · ESP matching ON · daily volume per the warmup ramp
  4. Sequences: use the approved v2 library (per-segment: absentee / owner-occupant / vacant), real name + real address signature, reply-to-opt-out line in the body
🚫 Launch gates — ALL must be true before the first real send: warmup ≥ 3 full weeks (first send 2026-08-18 or later) · placement test ≥ 90% inbox · list verified through steps 4–5 · anyone who ever opted out stays suppressed forever.

♻️ Rhythm & rules of thumb

  • Judge no list before ~100 sends. Track replies per lane; winners get refreshed/scaled next cycle, losers get retired for a bench signal.
  • Data goes stale in ~45 days — export → verify → send within the same month.
  • Inbox capacity is the real constraint, not credits: ~250 new contacts/month at launch ramp. Don't hoard giant lists.
  • Smart lists (built in the DealMachine UI) refresh daily by themselves — re-export a lane next cycle to pick up new matches (repeat properties are free within a cycle, re-billed after reset).
  • Questions / anything weird → ask Claude (deal-hunter skill has the full spec behind this page).
